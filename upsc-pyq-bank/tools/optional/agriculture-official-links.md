# Agriculture optional: official UPSC question papers (Civil Services Main)

Found on https://www.upsc.gov.in/examinations/previous-question-papers (2024-2026) and https://www.upsc.gov.in/examinations/previous-question-papers/archives (2016-2022).
UPSC lists no optional-subject papers for the 2023 Civil Services Main on either page, so the ten years available are 2016-2022 and 2024-2026.

UPSC's server drops PDF downloads from the build environment, so these have to be downloaded in a normal browser and put in the Drive folder `Optionals PYQ / AGRICULTURE` (Paper 1 and Paper 2 folders), named with the year, e.g. `2019_Agriculture_Paper_I.pdf`.
